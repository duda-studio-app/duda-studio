# Duda Studio

Public info site for **Duda Studio**, a web app that lets creators publish their own videos to their own TikTok account via TikTok's official Content Posting API (Direct Post).

- Home: https://melocalex.github.io/duda-studio/
- Terms of Service: https://melocalex.github.io/duda-studio/terms.html
- Privacy Policy: https://melocalex.github.io/duda-studio/privacy.html
- OAuth redirect URI: https://melocalex.github.io/duda-studio/callback.html
  (if `state` starts with `ds-local.`, it forwards `?code&state&scopes` to the Duda Studio app at http://127.0.0.1:5055/oauth/callback)
